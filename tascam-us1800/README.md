# TASCAM US-1800 Native Driver Suite (macOS Apple Silicon & Linux)

**TASCAM US-1800** — легендарный 16-входовой / 4-выходной USB 2.0 аудиоинтерфейс. Официальные драйверы от производителя для macOS перестали работать с переходом на 64-битные системы и архитектуру Apple Silicon (M1/M2/M3/M4), так как являлись устаревшими kernel extensions (`.kext`).

Данный проект — это **полнофункциональный нативный драйвер нового поколения**, написанный с нуля на основе обратного инжиниринга протокола устройства. Драйвер работает в пространстве пользователя (userspace) через **Apple IOKit** и **CoreAudio HAL**, не требует отключения SIP (System Integrity Protection) и обеспечивает стабильное студийное качество с минимальной задержкой.

---

## Ключевые возможности

* **Полная нативная поддержка Apple Silicon (ARM64) и Intel (x86_64):** macOS 12 Monterey, 13 Ventura, 14 Sonoma, 15 Sequoia+.
* **Прямая интеграция с macOS CoreAudio:** Карта определяется как полноценное системное аудиоустройство `TASCAM US-1800` в «Настройках звука», Audio MIDI Setup и во всех DAW (Studio One, Logic Pro, Reaper, Ableton Live, Cubase, FL Studio).
* **16 Входов (Capture):**
  * Каналы 1–8: Микрофонные/линейные XLR входы на передней панели (с фантомным питанием +48V)
  * Каналы 9–10: Инструментальные (Hi-Z гитара/бас) / линейные входы
  * Каналы 11–14: Балансные линейные входы 1/4" на задней панели
  * Каналы 15–16: Цифровой коаксиальный вход S/PDIF
* **4 Выхода (Playback):**
  * Каналы 1–2: Основные мониторные выходы Main Outs / наушники Phones
  * Каналы 3–4: Линейные выходы Line Outs 3 & 4
* **Аппаратная PLL-синхронизация частоты (Feedback Endpoint 0x81):**
  * Частота отправки пакетов с точностью до долей сэмпла подстраивается под физический кварцевый генератор ЦАПа карты через аппаратный IIR/PLL-фильтр.
  * Полное отсутствие клиппинга, треска, щелчков и цифрового шума квантования («биткрашера»).
* **100% Bit-Perfect Direct 24-bit PCM:** Чистый 24-битный звук (S24_3LE) без апсемплинга, ресэмплинга или модуляции питча.
* **CoreMIDI Virtual Ports:** Полноценный прием и передача физических 5-pin DIN MIDI сообщений через системный стек macOS CoreMIDI.
* **Linux ALSA Driver:** В репозитории также содержится модуль ядра для Linux (`linux-driver/`).

## Быстрая установка (macOS)

### Способ 1: В один клик (Рекомендуется)
1. Скачайте архив или склонируйте репозиторий.
2. Подключите звуковую карту **TASCAM US-1800** к вашему Mac через USB.
3. Дважды щелкните по файлу **`Установить_драйвер.command`** (или **`Install_Driver.command`**).
4. Введите пароль администратора в открывшемся окне Терминала.
5. После завершения откроются «Настройки звука» — выберите **TASCAM US-1800** в качестве устройства вывода и ввода!

### Способ 2: Через Терминал
```bash
git clone https://github.com/your-username/tascam-us1800.git
cd tascam-us1800
sudo ./mac-driver/install_hal_driver.sh
```

Скрипт автоматически:
1. Установит CoreAudio HAL плагин `TASCAM_US1800.driver` в `/Library/Audio/Plug-Ins/HAL/`.
2. Установит бинарный аппаратный движок `tascam_live_engine` в `/usr/local/bin/`.
3. Зарегистрирует системную службу LaunchDaemon (`com.tascam.us1800.live`) для автоматического запуска при старте системы и горячем подключении USB.
4. Перезапустит службу `coreaudiod`.

## Техническое описание архитектуры

1. **Разделение CoreAudio и USB IO:**
   * Драйвер CoreAudio HAL (`TASCAM_US1800.driver`) работает внутри процесса `coreaudiod` и отвечает за синхронизацию таймингов хоста (`GetZeroTimeStamp`) и обмен PCM данными с аудио-приложениями.
   * Аппаратный движок (`tascam_live_engine`) работает с наивысшим приоритетом реального времени (`THREAD_TIME_CONSTRAINT_POLICY`) и напрямую управляет физическими USB-пакетами.
   * Связь между ними организована через lock-free разделяемую память (`/tascam_us1800_shm`) с защитным кольцевым буфером на 32768 фреймов.

2. **Аппаратный изохронный фидбек (Feedback Endpoint 0x81):**
   * В протоколе TASCAM US-1800 контроллер отсылает отчеты о реальном потреблении ЦАПа (3 байта = сэмплы за последние 3 миллисекунды).
   * Движок сглаживает отчеты через фазовый PLL-аккумулятор:
     $$\text{freq\_q16} = \frac{3 \cdot \text{cur} + \text{target}}{4}$$
   * Благодаря этому буфер ЦАПа никогда не опустошается и не переполняется.

3. **Деинтерливинг 16 входных каналов:**
   * Пакеты захвата с EP 0x86 приходят блоками по 64 байта в бит-слайсовом кодировании. Движок распаковывает биты на лету в 24-битные линейные PCM сэмплы (`S24_3LE`) и нормализует их в Float32 для CoreAudio.
